# Scrcpy Plus 正式图标实施计划

**目标：** 将用户确认的浅色、深色、单色双屏加号方案制作成正式资源，替换旧品牌图标，支持 macOS 系统图标外观。

**设计：** [已确认方案](../../design/scrcpy-plus-icon/README.md)。矢量轮廓统一，单色版的交叠留缝用于全部外观，避免切换时形状跳变。应用内图标随窗口主题；macOS Dock/Finder 使用 Icon Composer 原生资源，由系统管理外观，保留传统 ICNS 回退。采用现有 Electron/React/electron-builder，不升级依赖。

- [x] 用统一几何生成三版 SVG、PNG、Windows ICO 与分层 `build/ScrcpyPlus.icon`，检查透明边缘和 16/32/64 像素表现。
- [x] 替换关于、更新窗口图标，沿用已有主题机制；为打包指定 `.icon`，核对 Xcode 26+ 工具链与原生 Assets.car/ICNS 输出。
- [x] 验证资源、界面切换及 macOS 包内容、签名和 Icon Composer 原生渲染；运行相关检查和构建。后续已更新本地安装并实测 Dock/Finder 浅→深→浅及着色，Finder 退出应用后仍能切换，完成后恢复原系统设置。
- [x] 更新构建说明、维护状态和验证证据，准确记录未验收的平台范围，见[维护记录](../../maintenance/app-brand-icon.md)。

**重点：** 单色交叠可辨识；浅深图标几何一致；用户强制窗口主题不覆盖系统 Dock 图标风格；Finder/未运行状态使用 bundle 资源；旧系统与 Windows 仍有静态回退。当前用户已授权实施，本轮直接执行，不再次要求设计审批。
