# 1.0.5 UI 第一阶段 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已确认的轻量桌面工作台用于真实主窗口，交付导航、设备入口、无设备引导与概览，保留所有现有功能入口。

**Architecture:** 沿用 MobX/observer 与现有设备 IPC。在 `main/components/workspace/` 增加局部 UI 外壳和样式；保留主窗口已有设备 key 重建边界及已访问页持续挂载。新 token 仅在主窗口根节点生效，独立窗口完全不接入。

**Tech Stack:** Electron / React 19 / TypeScript / SCSS Modules / MobX / 本地 Luna / Node test + JSDOM。

**Spec:** [设计文档](../specs/2026-11-03-v1.0.5-ui-design.md)；[版本路线](2026-11-03-v1.0.5-ui-roadmap.md)。本计划仅覆盖 UI-1，其他阶段在路线表跟踪。

## Global Constraints

- 投屏和升级界面保留现有设计：不修改 `renderer/screencast/`、`renderer/update/`、全局主题或其依赖样式。
- 继续使用 Electron + React + TypeScript、MobX/observer、SCSS Modules 和本地 Luna，不新增依赖。
- 最小窗口仍为 960×640；1100px 以下侧栏收为 64px，设备选择器可浮层展开。
- 设备页 ID 保持 overview/application/process/shell/layout/screenshot/hilog/webview，旧配置和未知 ID 均可启动。
- 中英文新增词条同时提交，所有可见文案使用 t()。
- 本阶段保留原设置弹窗、端口映射、遥控功能；设置页/抽屉在 UI-3 迁移，不假装已完成全量重构。
- 检查结果分清单测、模拟浏览器、Electron、设备与跨平台；禁止将一类当成其他类通过。

## Review Focus

- 已保存的无效 panel 导致所有内容隐藏：Task 1 通过生产 store 初始化测试回退概览。
- 已访问终端切页丢失会话或隐藏控件可被 Tab 访问：Task 1 实际 React 组件测试挂载计数、inert 与 aria-hidden。
- 同 tick 重复刷新/切设备后旧回复覆盖新结果：Task 2/3 保留现有回归并补设备选择器忙碌测试。
- 960px 英文设备名过长、布局三栏被挤压：Task 2 验证 64px 侧栏，保留原 700px 以上工作区；真实布局适配留 UI-5。
- 主窗口 token 泄漏到投屏和更新：Task 3 源码 diff 审计和构建；不得修改全局主题生成物。

## Task 1: 面板生命周期与持久导航兼容

**Files:** 新建 `src/renderer/main/components/workspace/Panel.tsx`、`Panel.module.scss`；修改 `main/App.tsx`、`main/store/index.ts`；新增 `test/workspace-panel.test.cjs`，扩展 `test/target-refresh.test.cjs`。

**Interfaces:** `Panel({id: string, active: boolean, children: ReactNode})`：首次激活挂载，之后保留；隐藏时 `inert`、`aria-hidden`、visibility:hidden；`store.selectPanel(panel: string)` 保持签名并验证既有 ID。

- [x] 先添加真实 React 面板用例：未访问子组件不挂载；激活一次；切走后节点仍在但 inert/aria-hidden；切回不增加挂载次数；设备 key 变更时销毁旧组件。
- [x] 在现有 store fixture 中加入初始化非法 panel → overview、合法 ID 保持、非法 selectPanel 不产生空白页的断言；运行新用例观察缺失行为失败。
- [x] 实现独立 Panel 和 store 归一化，替换 App 内旧 Panel；不将页面切换等同设备切换。
- [x] 运行 `node --test test/workspace-panel.test.cjs test/target-refresh.test.cjs test/webview-lifecycle.test.cjs`，预期全部通过。

## Task 2: 主窗口局部样式与导航

**Files:** 新建 `components/workspace/Workspace.tsx`、`Workspace.module.scss`、`DeviceSwitcher.tsx`；修改 `App.tsx`（旧 `App.module.scss` 暂保留）、`common/langs/{en-US,zh-CN}.json`；新增 `test/workspace-navigation.test.cjs`。

**Interfaces:** `Workspace({children: ReactNode})` 消费现有 store；`DeviceSwitcher()` 读 targets/target/targetsError，调用 selectTarget/refreshTargets；不增加 IPC。设置按钮调用现有 SettingsModal；设备页仍使用旧 panel ID。

- [x] 测试真实侧栏按钮调用正确 panel、无设备投屏禁用、设置可打开、设备选择保留完整 key、重复刷新只派发一次、失败和空列表分开、unmount 后不更新 UI。
- [x] 用 SCSS Module 在 workspace 根设置局部颜色（浅色 #F5F6F8/#FFFFFF/#20242B、深色 #17191D/#202329/#F0F2F5）、蓝色强调与尺寸；依赖 store.theme 切换，不改全局样式。
- [x] 实现分组导航（设备：概览/应用/截图；调试：终端/日志/进程/布局/WebView）、设备弹层和公共页头；侧栏标准 200px，≤1099px 为 64px 图标栏，有 title 与可访问名称。
- [x] 保留设置入口；关于入口复用现有窗口/菜单能力，若无可调用 renderer API 则本阶段保持原生菜单入口，不新增 IPC。
- [x] 运行 `node --test test/workspace-*.test.cjs`、`npm run lint`、`npm run build:renderer`，预期退出 0；检查同宽度下英文长文案、设备弹层与八页工作区。

## Task 3: 设备概览、无设备引导与阶段验证

**Files:** 修改 `overview/Overview.tsx`/`.module.scss`、双语词典；更新 `test/overview-lifecycle.test.cjs`、`test/overview-refresh.test.cjs` 以新可访问按钮为入口；增加失败持久反馈/未知值不复制/刷新不丢已有内容的行为断言。

**Interfaces:** `Overview()` 继续消费 `store.target` 和 `main.getOverview(key)`；保持 readSession 代次校验与重复刷新锁。保留端口/遥控弹窗和 HDC CLI；无设备提供检测和设置入口，使用显式 props 回调 `onOpenSettings?: () => void`。

- [x] 先在概览测试中断言刷新期间旧详情仍在且忙碌可见，失败后清空旧信息并显示可重试错误，断连后迟到结果无效；运行观察预期失败。
- [x] 将概览改为页头、设备身份、系统/硬件分组、设备工具。所有真实参数沿用现有字段，未知内存/ABI 不拼成 NaN/undefined，不显示无法证实的 USB/在线电量。
- [x] 复制参数使用真实按钮与键盘语义，缺失值禁用；错误与未连接有不同提示，刷新中旧数据有 busy 状态。全部新增文案双语。
- [x] 运行全部定向测试、`npm test`、`npm run lint`、`npm run build`，读取退出码和测试数量；纯视觉使用实际渲染，不写样式字符串快照。
- [x] 本机隔离 Electron/浏览器验证深浅色、中英文、最小尺寸、设置弹窗、设备刷新和八页导航；无真机时用模拟数据辅助视觉，真实设备流程保留待验收。
- [x] 独立审查最终 diff，修复重要问题；更新架构导航、RUNBOOK、来源记录和阶段证据。若无发布授权不上传或发布；不覆盖本机安装。
