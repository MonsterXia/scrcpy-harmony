# 1.0.5 UI-2～UI-7 连续实施计划

授权：用户于 2026-11-03 明确“不用和我确认，推进直到最终”。按已确认设计持续完成所有剩余源码阶段、审查和可用环境验证，不逐阶段停下询问。版本路线、验收边界以 [roadmap](2026-11-03-v1.0.5-ui-roadmap.md) 为准。

## Global Constraints

- 投屏与升级保留现有设计；不修改这两个 renderer、共享全局主题/生成样式，不变更设备协议和升级算法。
- 保留 Electron/React/MobX/SCSS Modules、Luna 数据引擎和 xterm；不增加依赖。所有新增业务/共享文案同步中英文。
- 主窗口至少 960×640，独立进程窗口至少 640×480；长文本可换行/滚动，常用动作可通过键盘访问。
- 保留旧面板 ID 与偏好，设备切换使旧请求失效，页面切换保留终端/日志实例。应用级设置在设备重挂载边界之外。
- 对行为变化先补真实组件/模块测试并记录失败再通过；纯样式以实际渲染验收，不写样式文本镜像测试。
- 分阶段提交可回退代码，串行改实现和词典，每阶段定向测试、lint 和 renderer 构建；最后完整测试/构建和独立审查。
- 已有公开版本仍是 1.0.4；本轮交付 UI 重构和本机候选验证，不自动上传或公开 Release。完成本地审查后准备草稿 PR 运行现有五项 CI；CI 安装冒烟与人工跨平台/设备矩阵分别记录。没有可用环境的验收项明确保留。
