## 兼容性与门禁

- Plus 的 appId 为 `io.scrcpyplus.desktop`，与公开 Harmony 版本不同。沿用独立安装/独立配置：不自动搬移、合并或删除 Harmony 的配置，不声称旧配置已迁移。README 和安装步骤须解释更名、共存和配置位置。
- 既有 Plus 本地开发版更新需保留自身设置。验收必须使用隔离目录，不覆盖日常配置；Harmony→Plus 验证旧安装/配置保持，Plus 新配置正常建立并重启保留。
- 产品最终源 SHA、五项 CI、三平台 Build 和 tag 指向同一代码候选。发行工具分支固定该 SHA/run ID，独立复核后才操作草稿；不复用旧版数字/文件名/哈希。
- 发行附件为 Windows x64、macOS arm64/x64 三安装包及配套 3 blockmap、3 YAML、3 验证报告、SHA256SUMS、release-validation，再加 CLI/MCP 通用 tgz，共 15 项。以实际构建元数据校验文件名、size、SHA-512/SHA-256，禁止缺项发布。
- Windows 签名与 macOS ad-hoc/Developer ID、公证/Gatekeeper状态以实际报告为准。无证书 Mac 必须 deep/strict 校验通过；不改变系统保护。
- 媒体端口回环补丁必须完成补丁后未签名 Runner 编译。当前本机 Xcode 27.2 未接受许可；待用户在本机完成许可配置或使用已配置 Xcode 的受控环境。签名密钥、账号和设备私有内容不入证据。
- 本轮已授权执行发行。按计划逐项记录，不提前将候选、草稿、构建成功记为公开发布成功。
