# 多端投屏与统一设备概览（2026-11-16）

用户批准第二轮第一张设计，并补充深浅模式只有颜色不同。追加将侧栏重复设备选择器移入概览、支持 Android/Harmony，以及修复聊天 `01a1e385-35bd-7ff1-a58a-dea87637d397` 已定位但未修改的定时闪烁。

## 实现

- 分组设备列表、稳定 key 勾选、单台/批量启动、逐设备失败重试。已创建会话独立显示打开/停止，iOS 接收器单列。
- 排列作用于全部实际投屏窗口；焦点 API 不重建连接。主进程读取合并窗口与排列后的几何状态，避免 UI 只记录下拉框选择。
- 概览支持 Android/Harmony，选择器移入页面；Android 不调用 HDC，鸿蒙专用工具禁用且恢复到不适用页面时重定向概览。
- 概览以 key/平台/state 判断设备身份；普通发现轮询不清空内容、不重复读详情，切换/断连与失败/重试保持原有过期响应保护。
- Android 元数据复用活动 ADB 连接，临时读取结束后释放；停止中保留 USB 归属，清理完成才允许新读取。固定只读 shell、7.5 秒单命令超时、256 KiB 输出上限。
- 旧空态重复检测按钮移除，统一由概览顶部检测器管理组件生命周期；避免切换目标后旧检测状态永久禁用。
