## 证据区分

实际 Electron fixture 加载本次构建的 renderer，原生窗口标题明确标注“simulated data”。它验证布局、键盘和界面状态；设备与持久化边界被替换，不证明真实设备安装、卸载、端口写入、输入或截图捕获成功。模拟截图位于 [design/1.0.5-evidence](../design/1.0.5-evidence/)。

另一次完整生产入口使用隔离用户目录连接当前设备，概览读取和刷新成功。随后用户将该实例切换至投屏，自动化已停止操作该实例并保持其运行；不将观察到投屏窗口计作专项投屏验收。后续界面验收使用独立应用标识的 Electron 副本，未覆盖已安装应用。

探针迁移：应用探针采用语义搜索/操作入口，HAP安装探针保留旧已安装版本选择器兼容；枚举与元数据探针从应用级 settings 页启动，避免额外概览请求。此阶段只做语法检查，尚未执行这些设备探针。
