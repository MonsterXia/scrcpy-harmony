# 1.0.5 UI-1：主窗口与设备概览

日期：2026-11-03。基线 `895fd10`，工作分支 `codex/v1.0.5-ui-workspace`。用户已确认轻量桌面工作台草图，并授权分阶段重构；明确保留投屏与升级现有设计。本阶段为工作区源码交付，未提交/合入/发布，应用版本仍为 1.0.4。

## 实施范围

- 增加 Workspace、DeviceSwitcher 和 Panel：八页分组导航、公共标题/投屏入口、设备选择浮层与单次刷新、设置入口。主窗口标准侧栏 200px，低于 1100px 收为 64px 图标栏。
- 已访问页持续挂载；隐藏页使用 inert、aria-hidden 和 visibility，保持终端/日志等原有会话生命周期。设备 key 变化仍重建设备面板，设置弹窗在边界外。持久化非法 panel 回退概览。
- 概览提供设备身份、系统/硬件九项信息与工具入口；保留原 IPC。初次加载、无设备、读取失败分别展示；刷新已有信息时保留内容，失败清空并可重试，迟到结果按代次隔离。未知内存/处理器不显示 NaN/undefined，不复制未知值。
- 新 token 仅作用于主窗口，新增文案同时提供中英文。没有修改投屏/升级 renderer、全局 theme.json 或生成样式；没有引入依赖、IPC 或设备命令。设置/应用管理等页内布局仍属后续阶段。
- 10 个设备验证脚本适配新导航/刷新/字段语义。两个枚举探针使用合法 overview，初次枚举闸门保证先在测试进程隔离无关 getOverview IPC，再执行真实枚举/参数故障验证；报告明确 overviewIpcStubbed。此改动不表示本轮已运行真机探针。
