# Scrcpy Plus 1.0.5-dev.2 开发预发布

状态：**2026-11-17 开始执行发行准备，尚未公开。** 用户已明确授权按照[计划](../superpowers/plans/2026-11-16-release-1.0.5-dev.2.md)完成独立审查和全部发行验收后发布。稳定 Latest 保持 `v1.0.4`，保留旧开发版及附件。

## 变更

相对公开的 Harmony dev.1，包含已合入 PR #86–#90：多平台源码内置投屏、USB/会话恢复、设备工作区和双语即时切换、共享自动化服务与 CLI/MCP、USB iPhone 概览，以及实验性 WDA 控制/ReplayKit。具体范围以最终候选 SHA 为准。

Harmony 和 Plus 使用不同 appId、安装名和配置目录。此次是 Plus 的开发预发布，保留原 Harmony 安装与配置；不自动迁移或合并旧设置。已有 Plus 开发版更新继续使用 Plus 配置。更新器仅检查并打开下载页，手动安装。

## 发行门禁

待记录发行准备 PR、最终源 SHA、五项 CI、三平台 Build、Runner 未签名编译、独立审查、安装/更新矩阵、15 项附件重下载校验及公开后复验。源码、tag 和安装包必须对应同一固定候选；不将早期构建当作最终包验收。

本机 Xcode 27.2 许可尚未接受，未签名编译退出69；计划通过 macOS arm64 Build 使用 runner 已配置的 Xcode 验证回环补丁后的 Runner，不修改本机许可状态。

## 能力边界

iPhone 概览已有真机证据。WDA PNG/点击/手势/文字和 ReplayKit 已完成代码及自动测试；补丁后未签名编译待本次 Build。签名后的真机控制/视频、旋转/拔插、多机隔离和长期矩阵仍待办，作为实验能力披露。参考 [iOS USB 准备](../scrcpy-plus/ios-usb-wda.md)。

Windows签名、Mac ad-hoc/Developer ID、公证和Gatekeeper状态待读取本次包报告；不得沿用旧版签名结论。CLI/MCP通用包作为第15项附件单独验证，不依赖源码检出或Electron的node_modules。
