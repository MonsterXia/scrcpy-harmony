# Scrcpy Plus 1.0.5-dev.3 开发预发布

状态：**准备中，尚未公开。** 用户于 2026-11-18 明确授权发布下一开发版本。功能基线 `a5ddade`，目标 tag `v1.0.5-dev.3`；本版为 Pre-release，稳定 Latest 保持 `v1.0.4`，不覆盖旧 tag 或附件。执行步骤见[发行计划](../superpowers/plans/2026-11-18-release-1.0.5-dev.3.md)。

## 相对 dev.2 的变化

- macOS arm64 发行包自动完成 Developer ID 签名、app 与 DMG 公证、票据装订、Gatekeeper 和安装启动检查；装订后重新生成并校验更新 YAML/hash/blockmap。
- iPhone 设置支持应用内 Apple ID 登录、WDA 准备和续签；包含账号互斥、取消、资源预约、签名私钥保留和 WDA 编译缓存修复。
- 改善 iOS 重连、WDA 资源所有权与投屏加载状态；应用采用新的 Plus 自适应图标，统一公共弹窗和底部操作。
- 更新与反馈入口迁移到 `MonsterXia/scrcpy-plus`。本版支持 Windows x64 和 Mac Apple Silicon arm64，不提供 Intel Mac 安装包。

## 安装与边界

已有 Plus 用户手动安装本版，沿用原 Plus 配置；Harmony 与 Plus 的安装/配置身份不同，不自动迁移 Harmony 配置。更新器打开发行页供手动下载，不自动安装。开启 Beta Update 才发现开发预发布。

Windows 安装包仍未进行 Authenticode 签名。Mac 正式签名、公证以本版最终 CI 报告为准，不复用上一版哈希。独立 `scrcpy-plus-cli-1.0.5-dev.3.tgz` 包含 CLI/MCP 客户端，需要 Node >=22.12 及运行中的桌面应用。

iOS 功能仍为实验性：已有 macOS 登录、签名安装、启动、受控时钟触发真实续签及基础视频/输入证据，但最新 WDA 后台启动修复后的连续视频、干净主机/DDI、真实经过七天的续签、Windows 真机和长期连接矩阵未全部验收。不把构建与安装启动通过当作这些设备场景通过。详见[iOS 准备记录](../maintenance/ios-desktop-provisioning.md)及[独立审查](../maintenance/ios-provisioning-review-20261118.md)。
